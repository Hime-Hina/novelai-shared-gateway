## 选定后的单一路线与执行顺序

1. **固定转换输入**：记录四项选择、承诺接口范围、最终源 DB/cut/完整 manifest、旧发布及固定旧包、原图/保护内容清单、namespace 来源和选定私有材料；绑定唯一目标 Git/DDL/writer/event/reducer/金额格式。旧源保持封存，升级只用独立工作副本，输出目录全新且预先受保护。
2. **实现唯一 converter，先跑困难切片**：复用当前事实 owner、来源校验和完整提交，产出 building 新库、保护正文/BLOB/context、旧→新来源映射、安全核对报告及同 cut 新格式恢复源；所选私有字段须转换，原 v4 库不能直接作为新格式私有快照。切片覆盖 partial/未知元数据、13 键、三池正负权益与真实责任、会话撤销、已知/不可读副本、重复及 SQL 尾错。A 保原提交映射；B 保存有来源 opening；只实现选定路线。
3. **同规模转换与恢复**：用完整同规模副本逐实体/字节/余额/责任/键/回执核对，再以新格式公共事件和选定私有源联合恢复，验证重复零写、重启和故障。公共回放不复活认证；复用唯一 installer，所有验证通过才 ready，失败保留 building。
4. **同一候选发布验收**：固定实际发行物及 SHA，验证真实 HTTP/调度、历史/领取/防重、事件与私有恢复、迁移 reconciliation；测量 DB、备份、外存的容量与性能。合成存储和旧包恢复证据分别记录。
5. **准备并申请一次具体生产操作授权**：提交停新受理/派发、排空或合法保留未决、停止旧 writer、固定最终 cut、转换核对、安装/启动、切换与故障处置操作单，再取得生产执行授权。最终 cut 须重核所有权益、责任和键；生产迁移、对象重发布/删除及切换按明确授权执行。切换后已有新账或外存变化时，保留新事实，不能用旧快照覆盖回退。

正式 converter 命令与上线窗口在上述输入和验收完成后生成；现阶段执行准备见[原操作草案](H:/TEMP/novelai-migration-decision-operations-20261115/DECISION-OPERATIONS.md)。常规实现与验证可持续推进，四项选择集中提交维护者；生产操作授权留到具体操作单和同候选证据齐备时。
