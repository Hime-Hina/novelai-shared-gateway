# Nuxt 管理页（U02）

owner 与私有 admin 页面已迁入 `web/`，复用 Vue、TypeScript 和 Naive UI。
当前 Node 网关仍是唯一的鉴权、SQLite 写入和调度服务；Nuxt 网页服务不配置
上游凭据、不打开业务数据库，也不增加生产 API 代理。成员页基础与 U01 历史
验证见 [Nuxt 成员页](nuxt-member-portal.md)。

## 入口与分流

[Caddyfile.example](../Caddyfile.example) 保持两个入口：

| 入口 | 页面与认证 | API 去向 |
| --- | --- | --- |
| 公开 HTTPS `/owner` | Nuxt 页面；沿用成员 Cookie，网关验证 owner 身份 | `/api/member/owner/*` → 网关 18081 |
| 回环 HTTP `127.0.0.1:18082/admin` | Nuxt 页面；管理员 Key 放在 `x-admin-token` | `/api/admin/*` → 网关 18081 |

公开域名继续拒绝 `/admin*`、`/api/admin*`、`/api/health` 和 `/memory`。
私有入口显式 `bind 127.0.0.1`；页面和 `/_nuxt/*` 转给网页 3000，API/SSE
转给网关，保留即时刷新。仅网页分支启用压缩。

```sh
ssh -N -L 127.0.0.1:19080:127.0.0.1:18082 your-user@your-server
```

随后访问 `http://127.0.0.1:19080/admin`。私有反代保留浏览器的 Host（含
19080）和 Origin，不能改为上游 18081 或固定 localhost，否则同源校验会
失败。公开入口也不能伪装成 localhost。Compose 的网页与网关仍分别绑定
回环 3000、18081，互不依赖启停；SSH 隧道使用同源分流入口 18082。

保留 `/owner.html`、`/admin.html`、`/admin/members.html`，重定向到对应
规范页面；尾斜杠由 Nuxt 原生路由处理，避免配置重定向循环。开发环境由
Nuxt 直接提供这些页面，仅用 `nitro.devProxy` 转发 `/api`，无需另建代理层。

## 数据与编辑行为

- 管理摘要和 owner 用量通过 `useAsyncData` 在浏览器读取，设置
  `server:false`、`immediate:false`、`serialize:false`。敏感结果不进入
  SSR HTML 或 Nuxt payload；上游摘要只保留展示字段，不显示原 PST。
- owner 首次并行读取摘要与用量，沿用 SSE 失效通知，并在页面可见时每
  30 秒补读。私有 admin 不订阅 owner SSE，仅在可见时每 30 秒读取；
  隐藏停止计时，断开清空管理状态与凭据，旧连接响应不能恢复它们。
- 业务操作的 403 不直接视作退出。组件先用现有鉴权接口核验；确认权限
  失效才清空状态，网络异常或仍有效的业务拒绝保留草稿并显示错误。
- 私有 admin 沿用“记住当前会话”选择。旧 `localStorage` 凭据只作兼容
  读取，成功连接后迁入 `sessionStorage`（未勾选则不保留），并删除旧项。
- 成员创建、邀请、分发、停止接单、删除转交、分组份额、续用策略、上游
  凭据及运营损耗继续调用既有 API。owner 用量保留成员/模型/日期维度、
  订阅与购买分池、免费/退款记录和最近 50 条；未知耗时不当成零。
- Naive UI Tabs 使用原生 `show:lazy`：表单首次访问后保留，切换页签不
  丢草稿；损耗组件独立挂载，即使未打开设置页，也读取后台告警。
- 后台更新不覆盖脏草稿。版本 409 保留输入与编辑基线，要求重新核对；
  写操作不自动重试。删除仍先预览并核对完整成员名称。密码、Key、邀请
  分发弹窗关闭即清除敏感内容，迟到响应不能重新打开或填回。
- PST 写入成功后，即使后续额度查询失败，也清掉已提交的旧输入并明确
  提示“已更新、勿重复提交”；保存期间的新输入保留。上游维持暂停，确认
  额度后手动恢复，不把后续查询失败误报为写入失败。

合成分流 **21 项**及实际 Nuxt HTTP 合法别名检查。Caddy mock 只证明分流，

真实浏览器使用合成数据，已检查成员创建/邀请、Key 关闭清空、删除预览与
完整名称确认、分组 409 后草稿保留及保存到版本 3、owner 实时连接、私有
admin 定时读取与断开清空。以上不代表真实 Discord OAuth、真实 NAI 或
部署验收；未替换生产服务。
